## ✨ Key Features & Architecture

- **High-Contrast Editorial Aesthetics**: Clean White, Black, and Burnt Orange (`#FAFAF8`, `#171717`, `#EA580C`) design system with editorial typography.
- **Interactive 3D Profile Card**: 3D tilt response tracking mouse cursor movement, featuring real workstation photograph, floating tech chips (`ECE`, `AI & ML`, `PYTHON`, `SOFTWARE`, `HARDWARE`), and real-time identity badges.
- **Responsive 2-Column Hero**: 45% left editorial headline & CTAs, 55% right floating 3D visual.
- **Categorized Skills Matrix**: 29 interactive skill cards across **ECE CORE**, **PROGRAMMING**, **AI / SOFTWARE**, and **DEVELOPER TOOLS** with category filtering.
- **Featured Engineering Projects Showcase**:
  - *Intelligent Recommendation System for Personalized IDPs* (React, Next.js, FastAPI, Gemini API, SQLite)
  - *AI-Based Image Restoration for Semiconductor Inspection* (Python, Computer Vision, OpenCV)
  - *JARVIS Voice Assistant* (Python, Gemini API, LiveKit, WebRTC)
- **Project Execution Sandboxes**: Live interactive simulation tab inside project modals allowing telemetry testing.
- **Academic Timeline & Education Record**: B.E. ECE degree progression at VSB Engineering College, Karur.
- **Honors, Achievements & Certifications**: Hackathon recognitions, certifications, and credential details.
- **Interactive Resume Modal**: In-browser PDF preview and instant resume download.
- **Validated Contact System**: Direct email mailto integration, clipboard quick-copy buttons for phone/email, and responsive contact form.

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18+) and **npm** installed.

### 1. Clone the Repository

```bash
git clone https://github.com/Dharanesh05/DHARANESH-PORTFOLIO.git
cd DHARANESH-PORTFOLIO
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run Development Server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production

```bash
npm run build
```
